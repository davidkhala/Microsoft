# Teams app package
https://learn.microsoft.com/en-us/microsoftteams/platform/concepts/build-and-test/apps-package

An app package is a zip file that has the required resources to install and run your app in Teams, containing the following files:
- App manifest: `manifest.json`
- App icon
- Custom activity icons

## Build tools

Microsoft 365 Agents toolkit

[Developer Portal for Teams](https://dev.teams.microsoft.com/home) (aka. App Studio)
